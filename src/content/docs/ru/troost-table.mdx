В виноделии точность измерений играет решающую роль. Одним из важнейших инструментов немецкой энологической школы является **Таблица Трооста** (составленная Герхардом Троостом).

Она позволяет точно сопоставлять плотность сусла (выраженную в градусах Oechsle) с содержанием сахара и потенциальным алкоголем.

## Что такое Oechsle (°Oe)?

Градус Oechsle — это единица измерения плотности виноградного сусла, показывающая, на сколько граммов один литр сусла тяжелее одного литра воды при температуре 20°C. 

Например, сусло с плотностью 1080 г/л имеет $1080 - 1000 = 80$ °Oe.

<Note type="info">
Значение °Oe не равно напрямую граммам сахара. Сусло содержит и другие растворимые вещества (кислоты, пектины, минералы), которые также влияют на плотность.
</Note>
