# Claude Code Context: VinoFlowApp (Stateless Edition)

## Build and Lint Commands
- Dev: `npm run dev`
- Build: `npm run build`
- Typecheck: `npm run typecheck`
- Lint: `npm run lint`
- Test: `npm run test` (Vitest)
- E2E Test: `npx playwright test`

## Core Guidelines (NON-NEGOTIABLE)
1. **Zero Tolerance**: КАТЕГОРИЧЕСКИЙ запрет на `any` и `as any`. Используйте строгие типы.
2. **Verification**: Перед завершением задачи ОБЯЗАТЕЛЬНО запустить `npm run typecheck && npm run lint` в терминале.
3. **Documentation**: Каждый файл должен начинаться с блока документации на **РУССКОМ** языке (НАЗНАЧЕНИЕ, ЗАВИСИМОСТИ, ОСОБЕННОСТИ).
4. **i18n**: Полный запрет на хардкод текста. Обновлять `ru.json`, `de.json` и `en.json` одновременно.
5. **Language**: Комментарии к сложной логике внутри функций — только на русском языке.
6. **Mobile First**: Дизайн сначала для iPhone SE (375px) с использованием Tailwind CSS 4.

---

## 🏗 1. Документирование кода
Каждый файл должен начинаться с блока документации на **РУССКОМ** языке.
Удали все существующие комментарии на английском языке. Описывай сложную логику расчетов внутри функций на русском.

---

## 📱 2. Дизайн-система (Tailwind CSS 4)
*   **Mobile First**: Базовые классы — для мобильных, префиксы `md:`, `lg:` — для десктопа.
*   **Брендбук**: Цвет `brand-600` (#6453e9) и градиент `bg-tech-gradient`.
*   **HeroUI**: Все интерактивные элементы (кнопки, инпуты) должны наследоваться от HeroUI.

---

## 🌍 3. Интернационализация (i18n)
Полный запрет на хардкод текста.
*   Библиотека: `next-intl`.
*   Синхронизация: Добавил ключ в один файл — добавь во все три (`ru`, `de`, `en`).
*   Маршрутизация: Используй локализованный `Link` из `@/i18n/routing`.

---

## 🔐 4. Безопасная типизация (TypeScript)
*   Никаких `any`. Используй точные интерфейсы и литералы.
*   Пропсы компонентов: Обязательно `interface Props`.
*   Математика: Все формулы в `src/lib/calculations` должны иметь строгие числовые типы.

---

## 📦 5. Работа с данными (Stateless)
Приложение работает без базы данных. Состояние хранится только на клиенте.
*   **Локальное состояние**: Используется `useState` и `useMemo` для мгновенных расчетов.
*   **tRPC**: Используется для внутренней логики и организации API-слоя без внешних запросов к БД.
*   **Чистые данные**: В расчетах используются только числа. Единицы измерения и подписи добавляются через i18n в компонентах.

---

## 🧪 6. Тестирование
*   **Unit-тесты (Vitest)**: Обязательны для всех математических формул в `src/tests`.
*   **E2E-тесты (Playwright)**: Проверка доступности страниц и базового взаимодействия в `tests/`.

---

## 🏛 7. Архитектура Layout (Next.js 15)
*   `src/app/layout.tsx`: КОРНЕВОЙ. Содержит `<html>`, `<body>`, `globals.css`. Без бизнес-логики.
*   `src/app/[locale]/layout.tsx`: ЛОКАЛЬНЫЙ. Провайдеры и навигация. БЕЗ `html/body`.
*   `src/app/providers.tsx`: Должен использовать `LazyMotion` из `framer-motion` для предотвращения крашей.

---

## 📚 8. Knowledge Hub (MDX)
*   Статьи в `src/content/docs/[locale]/`.
*   Frontmatter: `title`, `excerpt`, `category`, `relatedTools`.
*   Таблицы в MDX: Писать на чистом HTML для стабильности рендеринга.
